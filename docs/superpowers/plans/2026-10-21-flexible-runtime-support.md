## Toolchain contract

- Use `24` for the Node development selector and `>=24` for package engines.
- Use Rust `stable` and compatible Cargo dependency ranges.
- Use compatible npm ranges in both packages, `~0.0.x` for patch-track `0.0.x` dependencies, and `save-exact=false`.
- Keep npm/Cargo lockfiles as reproducible resolved snapshots. Update manifest metadata without unrelated package upgrades.
- Make protocol generation record the supplied executable's observed version and hash, with runtime-specific output and byte-integrity checks. Never regenerate historical artifacts or invoke generation during an ordinary task.

Range conventions: [npm package manifests](https://docs.npmjs.com/cli/v11/configuring-npm/package-json/) and [Cargo dependency requirements](https://doc.rust-lang.org/cargo/reference/specifying-dependencies.html). Protocol reference: [Codex app-server](https://learn.chatgpt.com/docs/app-server). The runtime's startup observations, rather than a release label or generated reference alone, determine whether required behavior is available.
